# Spam-detector

**GitHub Project: Spam Email Detector using Python and Machine Learning**

I'm excited to share my latest project, **Spam Email Detector**, built using Python and Machine Learning.

The main goal of this project is to classify email content as Spam or Legitimate (Ham) and provide an additional phishing risk assessment.

**Key Project Outcomes:**

- Built a spam classification model using Naive Bayes.
- Achieved 100% accuracy, precision, recall, and F1-score in the displayed evaluation.
- Developed an interactive web application using Streamlit.
- Added spam probability scoring.
- Integrated phishing risk detection.
- Tested the application with real-world email text samples.

**Practical Testing Result:**

One test email was classified as Legitimate (Ham), with:
- Spam Probability: 49.8%
- Phishing Risk: 25/100 (Moderate Risk)
